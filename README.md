# Relatorio de Uso de Inteligência Artificial

1. Ferramentas Utilizadas

Utilizei principalmente a ferramenta Claude, pois foi a que apresentou melhor entendimento dos prompts utilizados durante o desenvolvimento do projeto.
Também realizei testes com outras inteligências artificiais, porém não obtive a mesma efetividade em comparação ao Claude.

2. Principais Finalidades de Uso

Senti a necessidade de utilizar IA principalmente para auxiliar na depuração (debug) de partes do código. 
Em diversos momentos, encontrei erros que persistiam mesmo após várias tentativas de correção. Nesse contexto, a IA foi um recurso importante 
para compreender melhor as causas dos problemas e identificar possíveis soluções.

2.1 Fase de Planejamento e Arquitetura

Durante a fase de planejamento, surgiram dúvidas relacionadas à estruturação da arquitetura do sistema. A utilização da IA facilitou o 
entendimento desses conceitos, contribuindo para um planejamento mais organizado das etapas do projeto e para uma melhor distribuição das atividades 
ao longo do período de desenvolvimento.

2.2 Fase de Desenvolvimento e Banco de Dados

Por estar desenvolvendo o sistema full stack individualmente, recorri à IA em diversos momentos para compreender erros de código e superar 
dificuldades técnicas. Isso evitou bloqueios em etapas que poderiam demandar muito tempo para serem resolvidas sem auxílio.

Como eu já possuía experiência com a ferramenta Diagram.io para modelagem de banco de dados, a utilização da IA nessa área foi mais limitada. 
Nesse caso, utilizei a ferramenta principalmente para validar algumas decisões de modelagem e confirmar se a estrutura proposta fazia sentido para os 
requisitos do sistema.

2.3 Fase de Segurança e Autenticação

O sistema não possui mecanismos avançados de autenticação e segurança. Por esse motivo, a IA foi pouco utilizada nessa etapa. Em vez disso, 
busquei opiniões de terceiros para validar se as decisões adotadas estavam adequadas aos objetivos do projeto.
